这一页既是排版样式的速查，也是写作模板。
可以直接复制结构，把内容换成你自己的。

> 核心思路：**能做成表格的，就不要写成段落。**
> 一条数据只需要一个字段名、一个值、一句出处，不需要起承转合。

## 数据条目模板

参数、规格、测量值这类内容，用「小标题 + 表 + 一行说明」就够，不用写引言和总结。

### 示例：某型号三极管关键参数

| 参数 | 符号 | 数值 | 条件 | 出处 |
| --- | --- | --- | --- | --- |
| 集电极-发射极击穿电压 | V(BR)CEO | 40 V | IC = 1 mA | 数据手册 p.2 |
| 集电极最大电流 | IC | 200 mA | — | 数据手册 p.1 |
| 直流电流放大倍数 | hFE | 100–300 | VCE = 5 V, IC = 2 mA | 数据手册 p.2 |
| 特征频率 | fT | 300 MHz | VCE = 10 V | 数据手册 p.3 |

实测值与手册值不一致时，单独列一行，写清楚测量条件：

| 参数 | 手册值 | 实测值 | 测量条件 |
| --- | --- | --- | --- |
| hFE | 100–300 | 214 | VCE = 5 V, IC = 2 mA, 25 °C |

### 代码

行内代码写作 `pnpm build`，行内链接写作 [Astro 文档](https://docs.astro.build)。

```ts
type Theme = 'light' | 'dark';

export function resolveTheme(saved: string | null): Theme {
  if (saved === 'light' || saved === 'dark') return saved;
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}
```

```bash
pnpm install
pnpm build
```
